# SAST Analysis

This folder contains the Static Application Security Testing (SAST) related files for the Library Management System.

The application was analyzed using **SonarQube** to identify security vulnerabilities and code quality issues.

The analysis focuses on the three vulnerabilities selected for Lab Assignment 3:

1. SQL Injection
2. Cross-Site Scripting (XSS)
3. Improper Input Validation

The detailed SAST analysis is documented in `SonarQube_Report.md`.

SonarQube screenshots and visual evidence of the analysis are stored separately in:

```text
secure_application/screenshots/
```
